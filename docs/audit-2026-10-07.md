# Q2 implementation audit — 2026-10-07

Reviewed Q2 Pod's power loop, player filter, visualizer, cache workers,
scrobble persistence and boot/build flow, and the Q2 Rockbox port's ALSA,
display, input, backlight and power paths. Existing uncommitted Q2 Pod
changes were preserved. This audit adds no dependencies and does not flash
the device or publish a release.

## Findings fixed

| Implementation    | Fault                                                                                                                                                                   | Change                                                                                                                                                                                                                                                 |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Rockbox ALSA      | The Bluetooth writer woke every 5 ms even while stopped.                                                                                                                | Poll every 100 ms while stopped, retaining the 5 ms playback interval. This reduces the nominal stopped writer wake rate from 200/s to 10/s (95%). Synchronous startup still primes the PCM; a writer already sleeping can take up to 100 ms to react. |
| Rockbox ALSA      | Short writes and `EAGAIN` discarded samples already consumed from Rockbox. Startup had a separate copy of the same faulty write loop.                                   | Retain the unwritten tail and use the same fill function during startup and ongoing playback.                                                                                                                                                          |
| Rockbox ALSA      | Cleanup freed `frames` before joining its reader thread. Device changes also reinitialized a live mutex and repeatedly registered cleanup.                              | Stop/close the reader before freeing its buffer; initialize the mutex and register cleanup once. Use atomic access to the writer stop flag.                                                                                                            |
| Rockbox ALSA      | Recovery and startup failures could spin under the PCM lock, and reconnect ignored parameter/start failures.                                                            | Yield after a recovered write error, return on failed startup/draining, and propagate reconnect configuration and start errors. Check PCM buffer allocation.                                                                                           |
| Rockbox input     | `poll()` kept reporting a dead input descriptor, allowing an infinite loop that also left keys held.                                                                    | Close descriptors on error/hangup and clear the affected input state.                                                                                                                                                                                  |
| Rockbox sysfs     | A failed integer conversion returned success; buffered write errors at close went unnoticed; string reads failed to distinguish I/O errors.                             | Require one integer conversion, check close results, and check `ferror()` for failed string reads.                                                                                                                                                     |
| Q2 Pod low power  | The CPU-hotplug crash marker's directory entry was not synced before offlining CPU1. A failed rename of an old marker allowed another attempt.                          | Sync the marker and its directory before hotplug, check marker close, and disable hotplug whenever an old marker was found, even if its rename fails.                                                                                                  |
| Q2 Pod MP3        | A negative seek indexed before the Xing table; seeking beyond the end produced a fraction above 1; nonfinite input was unsafe; CRC frames used the wrong header offset. | Clamp finite seeks to the track, reject nonfinite input, and account for the CRC bytes.                                                                                                                                                                |
| Q2 Pod visualizer | The idle frame counter could wrap on a very large block and resume unnecessary copying.                                                                                 | Saturate the idle state before adding frames.                                                                                                                                                                                                          |
| Q2 Pod scrobbles  | Failed archive writes could remove the only pending copy of listens and still report success.                                                                           | Check writes, flush, sync and close before removing pending entries, and report retirement failures.                                                                                                                                                   |
| Q2 Pod scrobbles  | Uploads disabled certificate and hostname verification when no card CA bundle existed.                                                                                  | Always verify TLS. Stock has no CA bundle: put `.scrobble.pem` on the card for uploading. Certificate failures retain pending listens.                                                                                                                 |

## Verification

Both Q2 Pod firmware variants build within the stock rootfs limit. Their
asset geometry, exclusions, identity/mismatch checks and dual-boot shell
checks pass. The MIPS suites pass 670 Stock and 967 iPod scenarios (1,637
total), including failed crash-marker rename and directory sync. They execute
the patched payload and compare the
Coverflow renderer with the native host renderer. The renderer check now
uses the host's native ABI; it does not need a 32-bit executable.

Native checks pass for PEQ parser/storage, DSP and editor, the visualizer,
scrobble batching/signatures/TLS options and archive failure, EPUB/text
processing, video helpers, and the added Xing parser regression check.
Rockbox builds for the Q2; its wheel, gain, DAC-filter and new runtime
regressions pass. Runtime checks cover short writes, `EAGAIN`, underrun,
device/start errors, idle polling, cleanup ordering, sysfs failures and
disconnected input descriptors. The native PCM and Xing checks use UBSan.

The standalone Q2 Pod 32-bit player and Coverflow host executables are
terminated by this sandbox with `SIGSYS`. Their full suites therefore
remain unverified here. MIPS execution and native renderer parity do pass;
these do not replace the remaining host checks or device testing.

Builds and detailed logs are under `/tmp/q2-audit-final-stock`,
`/tmp/q2-audit-final-ipod`, and `/tmp/rockbox-q2-master-manual-bt`.
The built files are for review/testing and have not been installed.

## Device checks still required

Measure screen-off playback and paused battery drain with fixed volume,
sample rate, radios and brightness. Compare Q2 Pod with Low power off/on,
and Rockbox over DAC/Bluetooth. The writer wake-rate reduction is a code
result, not a measured battery-runtime improvement.

Exercise Bluetooth loss/reconnection, pause/resume, sample-rate changes,
screen wake, repeated stock/Rockbox handoffs, charge-limit transitions and
CPU1 offline/online on actual hardware. The host mocks cannot verify the
proprietary driver timing, audible glitches or hardware power states.

Scrobble retirement is still an at-least-once operation: if an upload
succeeds and local retirement fails or power is lost, a later upload may
repeat those listens. Pending entries are retained instead of discarded.
Rockbox still delegates device shutdown and USB storage to the stock OS.
